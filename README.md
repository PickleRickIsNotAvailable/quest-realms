# Quest Realms - AI-Powered Multiplayer DnD Game

## Setup
1. Run `npm install`
2. Get a **free** Gemini API key from https://aistudio.google.com/app/apikey
3. Copy `.env.example` to `.env` and paste your Gemini API key
4. Run `npm start`
5. Open `http://localhost:3000` on all players' phones

## How to Play
1. One player creates a room (becomes Game Master)
2. Game Master sets the story premise/setting
3. All players (including GM) create their characters
4. GM starts the game - AI takes over storytelling
5. Each round, all players submit their actions
6. AI resolves outcomes based on character bios, dice rolls, and story context
7. Earn perk points to unlock random skills!
